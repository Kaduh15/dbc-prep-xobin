# Exercício 08 — Soma dos Dígitos

## Descrição do Problema
Retorne a soma dos dígitos de um inteiro, usando o valor absoluto (ignora o sinal).

## Parâmetros e Tipos Esperados
- n: int.

## Formato do Retorno
- int

## Casos de Exemplo
```text
[
    ([123], 6),
    ([0], 0),
    ([5], 5),
    ([-123], 6),
    ([999], 27),
    ([1024], 7)
]
```

## Restrição
- Trate entradas vazias quando fizer sentido.
- Assinatura em Python: `def soma_digitos(n: int) -> int:`
- Assinatura em TypeScript: `export function somaDigitos(n: number): number {`
