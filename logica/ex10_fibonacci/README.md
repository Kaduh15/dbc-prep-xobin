# Exercício 10 — Fibonacci

## Descrição do Problema
Retorne o n-ésimo termo da sequência de Fibonacci, com fib(0)=0 e fib(1)=1.

## Parâmetros e Tipos Esperados
- n: int (>= 0).

## Formato do Retorno
- int

## Casos de Exemplo
```text
[
    ([0], 0),
    ([1], 1),
    ([2], 1),
    ([10], 55),
    ([15], 610)
]
```

## Restrição
- Trate entradas vazias quando fizer sentido.
- Assinatura em Python: `def fibonacci(n: int) -> int:`
- Assinatura em TypeScript: `export function fibonacci(n: number): number {`
