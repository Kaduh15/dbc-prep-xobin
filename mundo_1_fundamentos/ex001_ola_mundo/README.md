# Exercício 001 — Olá, Mundo!

## Descrição do Problema
Crie um programa que escreva "Olá, mundo!" na tela.

## Parâmetros e Tipos Esperados
- Nenhum parâmetro.

## Formato do Retorno
- `str`: a mensagem literal `Olá, mundo!`.

## Assinatura Canônica
- **Python**: `ola_mundo() -> str`
- **TypeScript**: `olaMundo(): string`

## Casos de Exemplo
```
Input: (nenhum)
Output: "Olá, mundo!"
```

## Restrições / Edge Cases
- Função determinística: sempre retorna a mesma string.
- Sem entrada de usuário; todo I/O fica fora da função testável.
